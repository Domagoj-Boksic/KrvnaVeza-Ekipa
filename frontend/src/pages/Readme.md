# pages

U ovoj mapi se nalaze cijele stranice. Grade se pomoću dijelova iz mape 'components'.

## stil
imenovanje - PascalCasing, __Page.jsx
poveznica s backendom u 'services/'

## struktura
AuthPage.jsx - stranica za ulogiranje
HomePage.jsx - glavna stranica (trenutno samo za provjeru uspješnosti autentikacije)

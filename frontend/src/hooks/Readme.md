# hooks

U ovoj mapi se prikupljaju podaci iz poziva API, neki osnovni podaci te ih kasnije možemo jednostavnije koristiti u ostalim komponentama

## stil
imenovanje(context) - PascalCasing, ___Context.jsx<br>
imenovanje(hook) - camelCasing, use____.

## struktura
AuthContext.jsx - dohvaćanje podataka o korisniku<br>
useDropdown.js - struktura dropdowna i hendlanje klikova<br>
useNavLinks.js - rute na stranice koje postoje/će postojati<br>
